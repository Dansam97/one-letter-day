Entry for the make.fun bounty "One Letter for Your Day": the program writes exactly one letter to entry.txt — **U**, standing for "unhinged", the word for a day that came off its hinges. One character, no punctuation, no trailing newline, exactly as the gate requires.

## Run it

```sh
python3 main.py
```
